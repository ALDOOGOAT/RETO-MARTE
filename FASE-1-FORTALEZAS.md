# FASE 1: Identificación de Fortalezas y Áreas de Mejora

Este documento recopila el análisis introspectivo de cada integrante del equipo, sirviendo como base para la asignación de roles. Se han identificado fortalezas (materiales con los que construimos) y áreas de mejora (donde nos apoyaremos mutuamente).

**Fortalezas:**
1. **Liderazgo estratégico:** Capacidad para ver el panorama completo del proyecto y coordinar esfuerzos hacia una meta.
2. **Pensamiento lógico y estructurado:** Habilidad para descomponer problemas complejos en pasos accionables.
3. **Resolución bajo presión:** Toma de decisiones rápidas y asertivas en momentos de crisis o tiempos ajustados.
4. **Gestión de proyectos tecnológicos:** Experiencia en metodologías ágiles y seguimiento de entregables.

**Áreas de mejora / Oportunidades:**

2. Delegar tareas operativas para no saturarse y mantener la visión directiva.
3. Adaptar el lenguaje técnico de software a presentaciones comerciales simples.
